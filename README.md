# Uttarakhand Trails

Uttarakhand Trails is a travel website based on popular destinations in Uttarakhand. It is a frontend project where users can explore different places, view travel packages, check starting prices and fill out a basic booking form.

## About the Project

I created this website to practice building a multi-page website using HTML and CSS.

The website focuses on some popular and scenic places of Uttarakhand such as Mussoorie, Rishikesh, Nainital, Kedarnath and Valley of Flowers.

## Pages

- **Home** – Introduction to Uttarakhand Trails with a mountain-themed hero section.
- **Destinations** – Shows different destinations in Uttarakhand with images.
- **Packages** – Displays available travel packages, duration and starting prices.
- **Book Now** – Contains a basic booking form and pricing table.
- **Blog** – Contains a few travel-related posts about Uttarakhand.
